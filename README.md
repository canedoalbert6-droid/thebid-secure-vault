TheBid Secure Vault

A secure authentication mobile application built using Flutter and Firebase, implementing strict MVVM architecture, secure storage, and biometric authentication.

---

Features

- Email & Password Authentication
- Google Sign-In
- Facebook Login
- Email Verification
- Biometric Authentication (Fingerprint)
- Secure Storage using flutter_secure_storage
- Dark Mode Support
- Strict MVVM Architecture

---

Architecture

This project follows:

- MVVM (Model-View-ViewModel)
- Firebase Authentication
- Provider for State Management
